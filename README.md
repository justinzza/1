## 放入 GitHub

1. 解压文件包。
2. 先确认目标仓库确实专用于运营雷达。不要关联空仓库或与网站无关的仓库到当前生产项目。
3. 将包内文件放在仓库根目录；不要只上传 ZIP，也不要把所有文件再套进一层同名文件夹。
4. 不要上传 Vercel Token、GitHub Token、密码、.env 或 .vercel 本机目录。
5. 确认根目录能看到 index.html、styles.css、app.js、vercel.json 后，再连接现有 Vercel 项目。
